■ 과제 개요

   첨부한 HTML 시안(DN전기 SMART OPS)은 가상의 배전반 제조사를 위한 스마트공장 통합 관제 시스템

   화면 설계안입니다. 현재는 화면만 있는 정적 데모이며, 이를 실제 동작하는 시스템으로 구현해 주세요.


■ 요구사항


  1. 데이터베이스 설계

     시안의 수주–호기–공정–실적, 자재–BOM–재고, 검사–시험–이력 구조를 담을 수 있는 스키마를 설계하고

     ERD를 제출해 주세요. DBMS 선택은 자유이며, 선택 이유를 README에 간단히 적어주세요.

 
  2. 가상 데이터 생성

     수주 10건 이상, 공정별 실적, 자재·재고, 검사·시험 기록 등 시안 수준의 현실적인 데이터를

     시드 스크립트로 생성해 주세요. 스크립트 재실행 시 동일하게 재현되어야 합니다.


  3. 기능 구현(시안의 5개 탭 전체)

   ① 통합 관제 : KPI 카드·공정 라인 현황·주간 실적이 DB 집계 쿼리로 계산되어야 합니다.

                 실시간 알림은 최근 이벤트 목록 조회(폴링)로 충분합니다.

   ② 수주·공정 진척 : 호기별 진척 조회와 납기 역산 경보  : 시안에 명시된 로직

                     (잔여 공정 표준시간 합산 + 여유일 → 납기 대비 지연 위험 판정)을 서버에서 자동 계산

   ③ AI 배선검사 : 검사 실행 시 mock 판정 결과가 저장되고 해당 호기 이력에 연동

   ④ 자재·재고 : 수주 BOM 연동으로 현재고 대비 2주 내 소요를 계산해 부족/충분 판정과 발주 제안 표시

   ⑤ 시험·품질이력 : 시험성적 기록과 수주번호 하나로 수주→자재 LOT→공정→검사→시험 전 이력 추적 조회


■ 범위 제한 (중요)

  - 화면 디자인은 시안을 그대로 재현할 필요가 없습니다. 기능 동작이 확인되는 수준의 UI면 충분합니다.

  - 로그인/권한 관리, WebSocket 실시간 푸시, 모바일 대응은 범위 외입니다.

  - AI 검사는 실제 비전 모델이 필요 없습니다.
